# Student Attendance System in Java

A simple console-based Java application for recording student attendance and displaying an attendance report.

## Features
- Enter student names
- Mark students as present or absent
- Display the attendance summary

## Concepts Practised
- Java collections using `HashMap`
- Conditional logic, loops, and console I/O

## Getting Started
Use a compatible JDK and compile/run the Java source files from this repository. Check the source files for the main class name.

**Language:** Java · **Interface:** Console
